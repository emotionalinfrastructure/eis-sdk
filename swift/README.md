# Swift Implementations

Native Swift implementations of the Emotional Infrastructure OS.

| Directory | Description | Status |
|---|---|---|
| [`console/`](./console/) | Console prototype — Swift Package, fully buildable | Working |
| [`ios/`](./ios/) | SwiftUI iOS app scaffold | Requires Xcode project |

The console prototype contains the reference business logic (signal processing,
tone mapping, analytics, session logging, JSON export) that the iOS app builds upon.
